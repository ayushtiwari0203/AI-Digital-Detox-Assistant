# AI Digital Detox Assistant

An AI-based assistant designed to help users reduce screen time and improve focus using smart reminders and conversational interaction.

## Features
- AI chatbot for productivity support
- Focus tips and motivational nudges
- Simple and clean interface
- Built as an academic project

## Tech Stack
- Python
- Google Colab
- Machine Learning (basic models)
- HTML, CSS (for UI prototype)

## How to Run
1. Open the notebook in Google Colab
2. Run cells sequentially
3. Provide user input when prompted
